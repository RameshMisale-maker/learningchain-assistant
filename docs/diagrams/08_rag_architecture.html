Sapphirus AI Assistant: RAG architecture

How the chatbot indexes LearningChain and Sapphirus content and answers a visitor's question, drawn from the current code and configuration (19 Nov 2026). Stages outlined in light blue with a NEW tag were added this week.

Current configuration

Knowledge bases: LearningChain Product Help + Sapphirus Company (one combined assistant) Index: 83 documents · 1,279 chunks (22 / 841 LearningChain · 61 / 438 Sapphirus) LLM: openai/gpt-oss-120b on Groq, fallback gpt-oss-20b (free tier, ~200k tokens/day each) Embeddings: bge-small-en-v1.5 (local) Chunking: parent-child, structure + recursive (1,800 / 400 chars) Reranker: ms-marco-MiniLM-L-6-v2 CRAG: on (grade, filter, rewrite once; KB only) Conversation layer: on (8 intents, memory = last 8 messages) Query normalization: on (rules + rapidfuzz ≥ 80, LLM only for unknown words) Scope check: lenient (LLM or relevant passage ≥ 0.5 overrides the keyword router) Router: hybrid (multi-KB ratio 0.70) Grounding: lexical Web scraper: builtin (Firecrawl once FIRECRAWL_API_KEY is set) Demo: Streamlit Community Cloud from GitHub Production target: Docker Compose · nginx · PostgreSQL 16 (manual release, no CI yet)

Stage reference

StageWhat happensCode
Indexing
SourcesNEWLearningChain help-centre articles, FAQ and website pages; the user and admin training manuals and product deck (PDF); approved Q&A for both knowledge bases; and 57 public pages crawled from sapphirus.in (services, products, about, management, contact, certifications, careers, blog). Training PDFs stay out of public repositories because their screenshots contain student data.knowledge_bases/, datasets/, ingestion/web.py
Ingestion queueAdmin uploads, CLI sync, crawls, the web monitor and signed webhooks enqueue jobs. Failed jobs retry 3 times with backoff.ingestion/jobs.py, ingestion/automation.py
Validate & loadChecks file type, size, magic bytes and macros; SHA-256 skips unchanged files; text is extracted and cleaned. OCR is off.backend/security/upload_validator.py, ingestion/document_loader.py
Parent-child chunkingHeading-aware parents of up to 1,800 characters, split recursively into 400-character children with 80 characters of whole-sentence overlap. Chunks with injection attempts are flagged.ingestion/chunking.py
Vectorize & indexChild chunks are embedded with bge-small-en-v1.5 into Chroma, with a BM25 index alongside: 83 documents and 1,279 chunks across the two knowledge bases.ingestion/embedding.py, ingestion/vector_store.py, backend/retrieval/kb_index.py
Answering
APIToken auth and roles, rate limit, streamed reply. The Streamlit demo calls the same pipeline in-process instead.backend/api/routes_chat.py, streamlit_cloud/streamlit_app.py
Safety guardLength limit and prompt-injection screen; restricted topics (medical, financial advice, sexual, self-harm, violence, illegal) are refused before any retrieval. Checked on both the original and the normalized wording.backend/security/prompt_guard.py
NormalizeNEWFixes typos and SMS short forms (wt, hw, r, u, pls, abt), product names (saphirus → Sapphirus, leaning chain / LC → LearningChain) and misspelt domain terms with rapidfuzz (≥ 80). The LLM rewrites the question only when unknown words remain. The normalized question drives everything after this; the original is kept for logs.backend/routing/normalize.py, prompts/normalize_prompt.txt
Conversation layerNEWClassifies greeting, small talk, incomplete input, clarification, gibberish, out-of-scope, follow-up and knowledge questions, mostly by rules. Non-questions get a direct reply with no retrieval. Follow-ups ("tell me more", "explain the second point") are rewritten from the session history (last 8 messages).backend/routing/intent.py, backend/routing/router.py
Router + scopeNEWPicks LearningChain, Sapphirus or both (close scores search both). A keyword "out of scope" is no longer final: the LLM scope check or a relevant passage (rerank ≥ 0.5) lets the question through; only clearly unrelated questions get the polite out-of-scope reply. HR topics stay excluded.backend/routing/router.py, backend/services/chat_service.py
Golden matchApproved Q&A at 0.78 or above is returned verbatim; from 0.50 it joins the candidates for reranking.backend/retrieval/golden_matcher.py
Hybrid searchTop 20 dense + top 20 BM25 child chunks, filtered by access roles and fused with RRF; multi-part questions are also searched per sub-question.backend/retrieval/hybrid.py, backend/routing/decompose.py
RerankA cross-encoder scores each child chunk with its header and keeps the top 5 scoring at least 0.15.backend/retrieval/reranker.py
Corrective RAGNEWOne LLM call grades every selected passage; irrelevant ones are dropped. If none is relevant, the question is rewritten as a documentation search query and searched once more in the knowledge base (never the web). If the grader fails, the reranked passages are used unchanged.backend/retrieval/crag.py, prompts/crag_*.txt
AugmentMatched children are swapped for their parent sections (≤ 9,000 characters) and wrapped as untrusted, numbered sources. The system prompt tells the model to infer the meaning of informal or misspelt questions and never comment on spelling.backend/generation/prompt_builder.py, prompts/system_prompt.txt
Generateopenai/gpt-oss-120b on Groq (temperature 0, max 900 tokens); on a rate limit or outage it falls back to gpt-oss-20b, then to extractive answers.backend/generation/llm_client.py
Grounding checkRemoves invalid citations and checks sentences and numbers against the sources; failures return a source extract or the "insufficient information" reply.backend/generation/grounding.py
PersistMessages (the conversation memory), route, citations, latency, tokens, cost and feedback are stored per session.backend/db/repository.py
Deployment
CodeAzure DevOps (AI-Intern-Repo, branch Ramesh_Misale, folder sapphirus_chatbot/; PR to dev) and GitHub (RameshMisale-maker/learningchain-assistant). No .env, keys, indexes or training PDFs are committed..gitignore
Test & evaluate250 pytest tests with mocked APIs; the evaluation dashboard measures retrieval, generation (RAGAS) and end-to-end performance, and CRAG on/off.tests/, evaluation/
Production targetDocker image under Docker Compose with PostgreSQL 16 and nginx (TLS, rate limits); the API container also runs the ingestion worker and web monitor.Dockerfile, docker-compose.yml, deploy/
Live demoNEWStreamlit Community Cloud builds from the GitHub repo (Python 3.12, CPU-only torch), runs the same pipeline in-process, builds the index on start and shows the LLM status in the sidebar. The Groq key is set in the app's Secrets. Reboot the app after each push.streamlit_cloud/
