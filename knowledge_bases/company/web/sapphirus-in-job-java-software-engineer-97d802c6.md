### Java Software Engineer

Job Overview:

We are seeking an experienced and highly motivated Java Developer to join our team. The ideal candidate will have a strong background in JAVA, J2EE, and web application development, with additional experience in various web technologies and database management. You will be responsible for designing, developing, and maintaining high-quality web applications that meet our business needs.

Key Responsibilities:

· Design, develop, and maintain complex web applications using JAVA, J2EE, JSP, HTML, JavaScript, and CSS.

· Implement and consume REST and SOAP web services to ensure seamless integration with external systems.

· Work closely with database administrators to optimize queries and manage Oracle/SQL databases.

· Collaborate with cross-functional teams, including product management and QA, to deliver high-quality software products.

· Ensure the performance, quality, and responsiveness of applications by implementing best coding practices and design patterns.

· Troubleshoot, debug, and resolve software defects and issues in a timely manner.

· Participate in code reviews to maintain code quality and adherence to coding standards.

Must-Have Qualifications:

· Extensive experience in JAVA and J2EE development.

· Proven track record in web application development using JSP, HTML, JavaScript, and CSS.

· Experience with REST and SOAP web services.

· Proficiency in Oracle/SQL database management.

Good-to-Have Qualifications:

· Experience with cloud platforms such as Azure.

· Familiarity with open-source libraries and tools.

· Understanding of Agile development methodologies.

· Knowledge of front-end frameworks like Angular or React.

Educational Requirements:

· Bachelor’s degree in Computer Science, Information Technology, or a related field.
