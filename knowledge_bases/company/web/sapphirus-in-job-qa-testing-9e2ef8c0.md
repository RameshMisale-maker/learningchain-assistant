About the Role

We are looking for a highly motivated Software QA Automation Engineer with 3+ years of experience in Manual and Automation Testing. The ideal candidate should possess strong expertise in web application testing, automation framework development, API validation, performance testing, and Agile software delivery. The candidate should be capable of independently owning testing activities while collaborating closely with Business Analysts, Developers, Product Owners, and DevOps teams to deliver high-quality software.

—

Key Responsibilities

Manual Testing

· Analyze Business Requirement Documents (BRD), Functional Requirement Documents (FRD), User Stories, and Acceptance Criteria.

· Design, review, and execute comprehensive test scenarios and test cases.

· Perform Functional, Regression, Smoke, Integration, System, Exploratory, Compatibility, and User Acceptance Testing (UAT) support.

· Validate end-to-end business workflows and application functionality.

· Perform release validation, production verification, and sanity testing.

Automation Testing

· Design, develop, and maintain robust automation frameworks.

· Develop automated test scripts using Playwright and Selenium WebDriver.

· Implement automation using Cucumber BDD framework.

· Write reusable, maintainable, and scalable automation scripts.

· Execute automated regression and smoke test suites as part of release cycles.

· Integrate automation suites with CI/CD pipelines.

· Analyze automation failures and improve framework stability.

· Continuously enhance automation coverage and execution efficiency.

API Testing

· Perform REST API testing using Postman or equivalent tools.

· Validate request/response payloads, authentication, status codes, business validations, and API integrations.

· Automate API validation wherever applicable.

Performance Testing

· Design and execute performance, load, stress, and endurance testing using Apache JMeter or equivalent tools.

· Analyze performance bottlenecks and prepare performance reports.

· Work with development teams to identify and resolve performance issues.

· Validate application scalability and stability under varying workloads.

Defect Management

· Log, prioritize, track, and verify defects using Azure DevOps.

· Collaborate with developers to reproduce and resolve issues.

· Perform root cause validation and regression testing after fixes.

Test Management & Collaboration

· Participate in Sprint Planning, Daily Stand-ups, Backlog Grooming, Sprint Reviews, and Retrospectives.

· Estimate testing efforts and provide regular status updates.

· Review requirements and identify ambiguities or gaps before development.

· Work closely with cross-functional teams to ensure complete test coverage.

AI-Assisted Quality Engineering

· Utilize AI-powered tools to improve test case generation, automation development, defect analysis, and documentation.

· Evaluate and validate AI-generated test assets before implementation.

· Contribute towards continuous QA process improvements using AI technologies.
