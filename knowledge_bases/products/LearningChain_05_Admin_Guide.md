## Admin: How do I Configure Certificate Type without Template?

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/45460175940377-How-do-I-Configure-Certificate-Type-without-Template

Updated: 2025-04-08

Applies to: Admin.

(Video walkthrough: https://player.vimeo.com/video/1073450606)

- To add a certificate Type, click on the Certificates module and then click on the “Add Certificate type” Tab.

- Step 1: Firstly, enter the name of the certificate type and description. Description is required to show that particular Certificate Type in Physical Verification Dropdown.

- Step 2: Enter the Verification amount which is Mandatory field and Institution share amount if Required.

- Step 3: Enter the Generation Amount If required.

- Step 4: Click the checkbox “Logo in QR code” in “QR code Configuration” If the admin want to display the logo when QR code is Generated.

- Step 5: Click the Checkbox Blockchain QR code generation without Templates in “Template Configuration Module” If the user want to secure the Certificates without Templates.

Note: If we do not enable any of the case in Template Configuration module It will be accepted predefine as “Blockchain QR code generation without Templates”.

- The first eight fields are the mandatory fields during the creation of each Certificate Type, and the rest fields are Custom fields and we can Customize each field in settings Configuration which are

- Special Characters: We can use this configuration to enable special characters.

- Mandatory: We can use this configuration to mandate the input details during Generations and Verifications.

- Verification: We can use this configuration to view the respective details in Physical Verification view page.

- View in Visual Verification: We can use this configuration to view the respective details in Visual Verification page.

Once all the respective fields are configured, click on the create button, then the certificate type will created and will get a successful message.

## Admin: How do I Enable the Student Review Process

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/58685854445465-How-do-I-Enable-the-Student-Review-Process

Updated: 2026-06-06

Applies to: Admin.

(Video walkthrough: //player.vimeo.com/video/1198947019)

Step 1: Log in to the Admin Account

- Open the Admin Portal.

- Enter your credentials (Admin username and password).

Click on Login to access the Admin dashboard.

Step 2: Navigate to the Certificates Module

- Once logged in, Navigate to the Certificates Module in the side navigation panel.

Step 3: Configure the Required Certificate Type

- In the Certificate Module, select Add New Certificate Type or choose an existing type for editing.

Note: Please note that the Student Review Process feature is supported only during the creation of new certificate types. This functionality is not applicable to or configurable for existing certificate types after they have been created.

Step 4: Navigate to the Approvals Section

While creating a new Certificate Type, navigate to the Approvals section.

Note: The Student Review Process functionality is currently available only for the “Blockchain QR Code Generation with Templates” use case, specifically for customer-supplied certificate designs where either the certificate template or background is provided by the client.

Based on the client's requirements, the final template/background will be mapped to the preprinted certificate design, as per defined position and size of Blockchain QR Code.

Configuration Steps

- Enable the required approval workflow:

  - Single Certificate Generation

  - Bulk Certificate Generation

- Select the "Student Review Required" option.

- Once enabled, the Student Review Process will be activated for the certificate type.

Student Review Workflow

- A one-time review email will be sent to students, allowing them to verify their certificate details before certificate generation.

- Based on the students’ response, the administrator can take appropriate actions within the application:

  -  Correction Required – The administrator can update the certificate details as requested by the student.

  -  Details Matched – The certificate can proceed to the next stage of processing.

Important Considerations

- The Student Review email is sent only once.

- After the administrator updates the details based on the student's feedback, the review email will not be resent to the student.

Any subsequent correction requests must be managed directly by the administrator through the application workflow.

Step 3: Perform Generate Bulk In User Portal

Upload the student certificate PDF(s) provided by the client along with the corresponding metadata file.

- If individual student certificate PDFs are provided, upload them directly.

  - If a combined PDF containing multiple student certificates is provided, Use the option “Bulk PDF Split (Single multi-page PDF)” to split each PDF to dedicated student.

  - Once the metadata and certificate PDF files have been uploaded successfully, select Next to proceed to the approval stage.

Step 4: Send Records for Approval to the Admin Portal

On the confirmation page, review and validate all uploaded student details and certificate information.

Once the validation is complete, click Send for Approval. The selected records will then be submitted to the Admin Portal for further review and processing as part of the approval workflow.

Step 5: Log in to the Admin Account

- Open the Admin Portal.

- Enter your credentials (Admin username and password).

- Click on Login to access the Admin dashboard.

Step 6: Navigate to the Student Review Section

Once logged in to the Admin Portal, navigate to the Certificates module from the side navigation panel and select Student Review.

The Student Review page displays all records that are in the Ready for Review and are awaiting student verification.

Step 7: Access the Student Review Page and Send Review Emails

On the Student Review page, administrators can locate records using the available search and filter options. Records can be filtered using a combination of Batch Number and Generated Date, located at the top-left corner of the page. Additionally, administrators can search for individual student records and send review emails on a case-by-case basis.

To send review emails in bulk, click Select All to choose the required records and then select Send Bulk Email. The system will send Student Review emails to the email addresses associated with all selected student records.

Step 8: Track Email Delivery Status

After the Student Review emails have been sent, administrators can monitor the email delivery status from the status summary section located at the top-right corner of the Admin Portal.

The portal provides a real-time count of the following email statuses:

- Total – Total number of emails processed for delivery.

- Success – Number of emails successfully delivered to students.

- Failed – Number of emails that could not be delivered due to errors or invalid email addresses.

This status summary helps administrators track the progress of email distribution and identify any records that may require further attention.

(Video walkthrough: //player.vimeo.com/video/1198950580)

Note: Once the Student Review email has been successfully delivered, the student can access the review page using the unique URL provided within the email body. By clicking the URL, the student can view their certificate details and verify the information displayed.

The student can then take one of the following actions:

-  Reviewed – Confirms that all certificate details are accurate and no changes are required.

-  Request for Correction – Indicates that one or more certificate details require modification. The student can submit the correction request along with the necessary comments for administrator review.

Based on the student's response, the administrator can review the request and take the appropriate action within the application.

## Admin: How do I Access the Student Review Records and secure them into Blockchain?

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/58687350225049-How-do-I-Access-the-Student-Review-Records-and-secure-them-into-Blockchain

Updated: 2026-06-06

Applies to: Admin.

(Video walkthrough: //player.vimeo.com/video/1198951655)

Step 1: Log in to the Admin Account

- Open the Admin Portal.

- Enter your credentials (Admin username and password).

Click on Login to access the Admin dashboard.

Step 2: Navigate to the Certificates Module

Once logged in, Navigate to the Certificates Module in the side navigation panel and select Approvals.

Step 3: Accessing Student Review Records and Securing Certificates into Blockchain

The Administrator is responsible for reviewing student responses and ensuring that certificates are secured into the blockchain only after the student review process has been successfully completed.

Selecting the Appropriate Approval Type

To begin with, the Administrator must select the appropriate approval type based on how the certificates were generated in the User Portal:

-  Single Approval – Select this option if the certificate was generated individually through the User Portal.

-  Bulk Approval – Select this option if multiple certificates were generated simultaneously through the User Portal using the bulk generation process.

For Bulk Approval, the Administrator must first select the relevant Batch Number. Once the batch is selected, all associated student records will be displayed on the screen for review and processing.

Searching and Filtering Student Records

A dedicated Search Bar is available on the page, allowing the Administrator to quickly locate and filter specific student records using relevant search criteria such as student name, academic reference number, certificate name, or other available identifiers.

This feature helps administrators efficiently manage large volumes of student records and quickly access the required information.

Managing Student Review Status

The page provides a "Change Status of Student Review" option, which enables the Administrator to update the review status of student records whenever required.

Each student record contains a “Student Review Status” column that displays the current stage of the student's review process. The status can fall into one of the following categories:

Step 1: Pending

This status indicates that the student has not yet taken any action on the review email sent to them.

- The review email has been successfully delivered.

- The student has neither approved the certificate nor requested any corrections.

- The system is awaiting the student’s response.

Step 2: Correction Request

This status indicates that the student has accessed the review email and identified discrepancies or required changes in the certificate details.

- The student has requested modifications or corrections.

- The Administrator must review the requested changes and make the necessary updates before proceeding further.

- The certificate cannot be secured into the blockchain until the corrections have been addressed and the student completes the review process.

Step 3: Reviewed

This status indicates that the student has successfully reviewed the certificate details and found no issues or discrepancies.

- The student has approved the certificate information.

- No corrections have been requested.

- The certificate is eligible for the next stage of processing.

Review Status Summary

At the bottom of the page, a summary section is provided that displays the total count of student records under each review status category:

- Total Pending Records

- Total Correction Requests

- Total Reviewed Records

This summary allows Administrators to monitor the overall progress of the student review process and quickly identify records requiring attention.

Securing Certificates into Blockchain

Once a student record has been marked with the Reviewed status, the corresponding certificate becomes eligible for blockchain generation.
