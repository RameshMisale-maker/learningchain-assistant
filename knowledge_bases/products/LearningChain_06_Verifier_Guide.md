## Verifier: How do I Verify the Student Certificates

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/26476529810713-How-do-I-Verify-the-Student-Certificates

Updated: 2025-03-26

Applies to: Verifier (employer / third party).

(Video walkthrough: https://player.vimeo.com/video/1069516798)

- Once Login to the LearningChain web application, It will take us to the Landing Page of LearningChain.

- On the Dashboard Page, We can able to view the Verification URL

- Click on the Verification URL, It will redirect to the verification page.

First, select the certificate type to complete the 4-step verification process.

Step-1:

- Enter all the student details like Student Name, Student Email, Certificate Type, Certification Name, Issue Month, Issue Year, and Academic Reference Number.

- Enter Verifier details like Verifier Name, Verifier Email, and Verifier Mobile.

Step-2:

- Verifier needs to upload the Original Certificate File of the student.

• Once uploaded the files, click on the Next button.

Step-3:
• Verifier needs to pay the amount, So the amount will be credited to the University/College.

Step-4:

- In the Verification Summary page will display the verifier details, Blockchain details, and Student details as per verifier and as per Blockchain.

- On the above page, we can able to view the verification status along with the summary.
