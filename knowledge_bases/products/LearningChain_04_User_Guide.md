## User: How do I Secure the Student Digital Certificate without Template?

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/45494719356441-How-do-I-Secure-the-Student-Digital-Certificate-without-Template

Updated: 2025-04-19

Applies to: User (institution staff).

(Video walkthrough: https://player.vimeo.com/video/1076868459)

- To secure the student digital certificate. After logging in, click on Certificates Module and then click on Generate Single Tab.

- Select the Certificate Type from the dropdown.

Enter all the student details like Student Name, Student Email, Mobile Number, Academic Reference Number, Certificate Type, Certificate Name, Issue Month, and Issue Year etc. and Upload the document in digital format.

- After entering all the details click the guidelines Checkbox and click on Generate Certificate Button. Now the certificate will be pushed into the Blockchain and it will provide a unique QR code the certificate.

-  We can check the Generated certificates in the Reports Tab.

Note: We can also secure 'N' number of certificates into the Blockchain by using Generate Bulk Module. Here we need to upload the pdf file and also the respective meta data in Excel format as shown below.

## User: How do I Secure a Certificate with Embed QR Code

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/45495603501209-How-do-I-Secure-a-Certificate-with-Embed-QR-Code

Updated: 2025-04-19

Applies to: User (institution staff).

(Video walkthrough: https://player.vimeo.com/video/1076868439)

Step 1: Configure Certificate Type

- Log in to the Admin account.

Navigate to the Certificate Module and configure the required Certificate Type (e.g., Consolidated Memorandum of Marks).

Step 2: Access User Login

- Log in with your User Account.

- Go to the Certificate Module.

Select "Generate Single" from the drop-down menu.

Step 3: Select Certificate Type& Enter respective details

- Choose the Certificate Type created earlier (e.g., Consolidated Memorandum of Marks).

Ensure the fields are mapped correctly based on the selected Certificate Type.

- Enter all the respective details mapped as per the Certificate Type and double check the details to avoid errors

- Upload the document in Digital format in PDF format.

- Click on “Generate Certificate” so that Certificate will be uploaded into BlockChain.

- Then the respective Certificate will be generated with QR code embedded on the Certificate on the assigned position.

Note: We can also secure 'N' number of certificates into the Blockchain by using Generate Bulk Module. Here we need to upload the pdf file and also the respective meta data in Excel format as shown below.

## User: How do I Secure a Certificate with Pre-printed?

## User: How to Secure a Certificate with Pre-printed and Photo Field?

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/45499320230425-How-to-Secure-a-Certificate-with-Pre-printed-and-Photo-Field

Updated: 2025-04-09

Applies to: User (institution staff).

(Video walkthrough: https://player.vimeo.com/video/1073121470)

Step 1: Configure Certificate Type

- Log in to the Admin account.

- Navigate to the Certificate Module and configure the required Certificate Type (e.g., SSC).

- Ensure the "Pre-printed" field is set to True during configuration.

Enable the "Photo" field in the configuration settings to include student photos.

Step 2: Access User Login

- Log in with your User Account.

- Go to the Certificate Module.

Select "Generate Single" from the drop-down menu.

Step 3: Select Certificate Type

- Choose the Certificate Type created earlier (e.g., SSC).

Ensure the fields are mapped correctly based on the selected Certificate Type and Pre-printed.

Step 4: Enter Student Details

Before entering details, follow these guidelines for smooth workflow:

- Fill in all the required fields, including:
o Student Name
o Academic Reference Number
o Certificate Name
o Issue Month and Year
o Upload Student Photo (Ensure the photo meets the required dimensions and resolution).

Double-check the entered information to avoid errors.

Step 5: Generate Certificate

- Click the "Generate Certificate" button.

- The student details and photo will be mapped automatically onto the certificate template.

Verify the certificate to ensure all data, including the photo, is accurate.

Important Notes:
• Verify that the Pre-printed field is set to True during configuration.
• Ensure the Photo field is enabled and correctly mapped.
• Double-check all fields for correctness before generating the certificate.
• Use a high-resolution printer if printing the certificate to maintain quality.
• Contact support if you face any issues during the process.

Note: We can also secure 'N' number of certificates into the Blockchain by using Generate Bulk Module. Here we need to upload respective images in JPG format and also respective meta data needs to be uploaded in Excel format as shown below.

## User: How to Secure a Certificate with Pre-printed and Customer Supplied?

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/45497810637081-How-to-Secure-a-Certificate-with-Pre-printed-and-Customer-Supplied

Updated: 2025-04-09

Applies to: User (institution staff).

(Video walkthrough: https://player.vimeo.com/video/1073124588)

Step 1: Configure Certificate Type (Admin Login)

- Log in to the Admin Account.

- Navigate to the Certificate Module.

- Configure the required Certificate Type (e.g., Original Degree).

- Ensure that both the Pre-printed and Customer Supplied fields are set to True in the configuration settings.

- Save the configuration.

Step 2: Access User Login

- Log in with your User Account.

- Go to the Certificate Module.

Select "Generate Single" from the drop-down menu.

Step 3: Select Certificate Type

- From the drop-down menu, select the Certificate Type created earlier (e.g., Original Degree).

- Ensure the selected type matches the pre-configured template to enable accurate mapping of fields.

Step 4: Enter Student Details

Before entering details, follow these guidelines for smooth workflow:

- Fill in all required fields carefully, including:

  - Student Name

  - Academic Reference Number

  - Certificate Name

  - Issue Month and Year

  -  Additional custom fields (if needed)

Double-check the details to ensure accuracy.

Step 5: Generate Certificate

- Click the "Generate Certificate" button.

- The student details will automatically map onto the certificate template based on the selected type.

- Review the generated certificate to verify accuracy.

- Save or download the certificate as required.

Important Notes:

- Verify that both the Pre-printed and Customer Supplied fields are set to True during configuration.

- Double-check all fields for correctness before generating the certificate.

- Use a high-resolution printer if printing the certificate to maintain quality.

- To enable one more level of approval, navigate to the Admin Account and configure the setting by enabling the With Single Approval option.

- Contact support if you face any issues during the process.

Note: We can also secure 'N' number of certificates into the Blockchain by using Generate Bulk Module. Here we need to upload respective images in JPG format and also respective meta data needs to be uploaded in Excel format as shown below.

## User: How do I Reissue a Single Certificate?

Article: https://learningchainai.zendesk.com/hc/en-gb/articles/45542596479769-How-do-I-Reissue-a-Single-Certificate

Updated: 2025-04-09

Applies to: User (institution staff).

(Video walkthrough: https://player.vimeo.com/video/1073920097)

Step 1: Log in to the User Account

Open the User Portal.

Enter your User username and password.

Click Login to access the User Dashboard.

Step2: Access User Module.

- Once logged in as User, Click on Certificates module and then we need to Access "Single Reissue" option.

Step3: Select the Certificate type and click on "Actions" Icon to reissue the Certificate you wish to proceed.

Step4: Input all the respective details where the Reissue of the Certificate needs to be Initiated and upload the Document If required, as per the Certificate type Configuration.

- Once done, Click on "Send For Approval" so that Certificate will be processed to Admin for Approval.

Step5: Login into Admin and access Certificate module and Click on Approvals.

Step6: Click On "Single Approval" and then select the "Certificate type" and then click on "Select All" and proceed with Clicking on Generations so that Certificate will be reissued and we can access the reissued Certificate in Reports module in Generated Certificates Tab by filtering the Certificate type.
